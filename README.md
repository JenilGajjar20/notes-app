# notes-app

A simple yet powerful note-taking application built with Electron, React, and TypeScript. This application allows users to create, manage, and organize their notes efficiently. It provides a clean and intuitive user interface for a seamless note-taking experience.

## Features

- Create new notes
- Edit existing notes
- Delete notes
- Organize notes (e.g., into folders or categories - assuming this might be a feature)
- Simple and intuitive user interface

## Tech Stack

- **Electron:** For building cross-platform desktop applications.
- **React:** For building the user interface.
- **TypeScript:** For static typing and improved developer experience.
- **Vite:** For fast frontend build tooling.
- **Tailwind CSS:** For utility-first CSS styling.

## Project Setup

### Install

```bash
$ yarn
```

### Development

```bash
$ yarn dev
```

### Build

```bash
# For windows
$ yarn build:win

# For macOS
$ yarn build:mac

# For Linux
$ yarn build:linux
```
